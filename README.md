# DANN by PeGato

**Asistente personal inteligente para la gestion de proyectos, tareas y productividad.**

## Sobre el proyecto

DANN es un proyecto desarrollado en C# y .NET 10, enfocado en la organizacion de proyectos y tareas mediante una API REST y arquitectura por capas.

## Tecnologias

- C# / .NET 10
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- Git y GitHub

## Arquitectura

- **DANN.Domain:** entidades y reglas de negocio.
- **DANN.Application:** casos de uso y logica de aplicacion.
- **DANN.Infrastructure:** persistencia y acceso a datos.
- **DANN.Api:** controladores y endpoints HTTP.
- **DANN.SmokeTests:** pruebas automatizadas basicas.

## Funcionalidades

- Gestion de proyectos.
- Gestion de tareas.
- Seguimiento de progreso.
- Consultas y resumenes.
- API REST para integraciones.

## Estado

Proyecto en desarrollo activo. Las futuras versiones contemplan interfaces multiplataforma y funciones de inteligencia artificial.
